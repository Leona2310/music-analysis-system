# 🎵 Music Analysis System

An AI-powered music analysis application built using Python, Streamlit, and Machine Learning.

This system analyzes audio files and predicts music genres using extracted audio features and trained ML models.

---

## 🚀 Features

- 🎧 Upload audio files (.mp3, .wav, .au)
- 🎼 Genre prediction using Machine Learning
- 📈 Audio waveform visualization
- 🎵 Spectrogram analysis
- 🔍 Tempo and energy analysis
- 📊 Genre influence breakdown
- ▶️ Built-in audio playback
- 🔗 YouTube link estimation mode

---

## 🛠 Tech Stack

- Python
- Streamlit
- Librosa
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
- Joblib
